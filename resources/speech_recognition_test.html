ArkWeb · Web Speech API

语音识别测试 · SpeechRecognition

通过标准 Web Speech API 测试 HarmonyOS 端侧 ASR 引擎（@hms.ai.speechRecognizer）。 覆盖识别启停、语言约束、中间/最终结果、错误码与全事件流。

端侧离线引擎 · 仅支持中文
本实现走 HarmonyOS Core Speech Kit 离线模型，引擎仅支持 zh-CN（代码中对 zh 前缀做大小写不敏感匹配，zh-CN / zh-Hans / zh-TW 均可）。 选择其它语言会收到 language-not-supported 错误。识别结果 不携带 confidence（恒为 0），且无候选词列表。

Web Speech error 映射自 kit 错误码
adapter 把 Core Speech Kit 的 1002200xxx 系列错误码映射到右侧 Web Speech error 取值。
error 值含义kit 来源
no-speech未检测到语音kNoSpeech
aborted用户主动中止kAborted
audio-capture音频采集失败kAudioCapture
network其它 / 未知错误401 / 1002200009 等 → kNetwork
not-allowed无麦克风权限1002200012 → kNotAllowed
service-not-allowed引擎创建失败 / 忙1002200001/0006/0007/0008 → kServiceNotAllowed
language-not-supported语言不支持（非 zh）kLanguageNotSupported
no-match识别结束但无结果kNoMatch
