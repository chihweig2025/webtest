06 错误码参考

SpeechSynthesisErrorEvent.error 标准取值
TTS 失败、取消或参数非法时，utterance.onerror 会携带下列取值之一（由 Blink 按 Content 侧事件映射）。
error 值含义典型触发
canceled合成被取消调用 cancel()
interrupted被其它播报中断队列抢占 / 新会话
audio-busy音频设备忙其它应用占用音频
audio-hardware音频硬件错误设备异常
network网络错误在线语音依赖网络
synthesis-unavailable合成服务不可用系统 TTS 未就绪
synthesis-failed合成失败引擎异常 / 文本非法（空文本）
language-unavailable语言不可用lang 无对应引擎
voice-unavailable发音人不可用指定的 voice 失效
text-too-long文本过长超出系统限制
invalid-argument参数非法volume/rate/pitch 越界
not-allowed缺少权限用户/系统未授权

07 验收项自测清单

AC操作预期
AC-001输入文本 → 开始播报听到系统 TTS 声音
AC-002观察事件流同一 utterance 收到 start 且最终 end 或 error
AC-003等待 voiceschanged / 刷新 voicesvoices 非空，表格展示 name、lang
AC-004调整 volume/rate/pitch/lang/voice 后播报听觉变化或按底层裁剪，无异常
AC-005连播 3 条后立即取消播放立即停止，pending=false，队列项标记取消
AC-006播报中暂停 / 恢复真实暂停恢复，或受限降级（日志提示），后续 speak 不受影响
AC-007观察 boundary/mark 与主链路可能恒为 0，不影响 speak/cancel/getVoices
